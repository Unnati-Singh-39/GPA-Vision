# GPA Vision - Java
## Name: Unnati Singh  
## Registration Number: 24BAI10625

This repository contains Java programs created as part of my GPA Vision project.

The goal of this project is to help students **manage courses, calculate GPA, analyze performance, and plan for target GPA**. It provides insights beyond simple GPA calculation by giving semester-wise performance analysis and GPA prediction.

## What I Learned

- Java programming and OOP concepts (classes, objects, methods)  
- Grade and GPA calculations  
- Performance analysis logic  
- Planning for target GPA  
- Semester-wise data management and input handling  
- File handling and scalability considerations  

## Features

 | Feature                | Description                                                                    |
| ---------------------- | ------------------------------------------------------------------------------ |
| Add Courses            | Add courses semester-wise with course name, credits, and grade (S, A, B, C, D) |
| View Courses           | View all courses organized by semester                                         |
| GPA Calculation        | Calculate semester GPA and overall GPA                                         |
| Target GPA             | Calculate required GPA to reach a desired target                               |
| Performance Analysis   | Identify best and weakest subjects                                             |
| Predict Future GPA     | Estimate GPA based on planned courses                                          |
| Semester-wise Planning | Track courses semester by semester                                             |
| Flexible Input         | Dynamically input number of courses                                            |



## How to Run

1. Make sure **Java JDK** is installed.  
2. Open your terminal and navigate to the project folder.  
3. Compile the code:
javac Main.java Student.java Semester.java
4.	Run the program: java Main
5.  Follow the menu options to:
	•	Add courses
	•	View courses
	•	Calculate GPA
	•	Analyze performance
	•	Plan target GPA
